> 本路线与 [[Notes/SelfGameEngine/0_RoadMap|SelfGameEngine 构建手册]] **深度融合**。你的图形学知识不再是一条孤立的"理论线"，而是直接服务于引擎构建的"能力线"。
>
> **核心原则**：不在图形学里闭关修炼，而是在关键节点**切入引擎开发**，用工程需求反向驱动深度学习。
>
> **构建哲学**：先建立像素级直觉（软渲染器），再理解GPU如何替代你的for循环，最后把这些知识组织成引擎的渲染管线。

### 关键认知：这不是"先学后做"

传统思路：先花3个月把图形学学完，再开始写引擎渲染。

**本路线的思路**：
- 阶段一：建立像素级直觉（帧缓冲是什么），并在CPU上实现软渲染器（3D数学 + 光栅化 + 深度缓冲）。
- 阶段二：建立完整概念地图，理解GPU并行架构，并让GPU画出第一个三角形。
- 阶段二后：**切入引擎阶段1.2**——你有足够知识把"最简图形后端"从清屏升级到画三角形。
- 阶段四后：**切入引擎阶段5.1和5.3**——你有能力参与RHI和材质系统的开发。
- 阶段五后：**切入引擎阶段5.2和5.4**——你理解纹理加载、GPU上传、渲染生命周期。
- 阶段六后：与引擎阶段5.6完全对应，直接并行开发后处理。
- 阶段七：不再是"学图形学"，而是"在引擎里设计渲染架构"。

## 阶段一：像素直觉与软光栅化

**里程碑**：理解像素在内存中的表示，建立"3D世界 = 模型 + 材质 + 光源 + 相机"的直觉；并能在CPU上从零实现一个软渲染器——画线、填充三角形、做3D变换、投影到屏幕、处理深度。

> **与 SelfGameEngine 的关系**：本阶段为引擎阶段1.2 "最简图形后端"提供像素级直觉——清屏的本质就是填充帧缓冲中的像素；软渲染器则为引擎阶段3.2 "数学基础"和阶段5全模块提供渲染数学基础。
>
> **本阶段明确不包含**：图形后端的具体实现、GPU API调用、OpenGL/Vulkan代码、交换链管理、渲染上下文初始化。这些是阶段二~七的内容。本阶段只关注"算法本身"与"像素直觉"。

## 阶段二：从软光栅到 GPU 流水线

**里程碑**：能说清楚"我写的软渲染器 `for(y) for(x)` 循环"在 GPU 上被哪些机制替代，并能让 GPU 画出第一个彩色三角形。

> **与 SelfGameEngine 的关系**：本阶段对应引擎阶段1.2 "最简图形后端"的回探升级。你已经读过 [[Notes/SelfGameEngine/Hello-Engine-Window/最简图形后端|最简图形后端]]，但那篇文章侧重"初始化上下文和清屏"。本阶段在此基础上增加"画一个三角形"的完整链路，并明确回答"软渲染器的每个步骤对应 GPU 管线的哪个环节"。

**验收标准（能看见的）**：
- [ ] 能画出软渲染器 `for(y) for(x)` 循环与 GPU 管线的逐项映射图

- [ ] 能解释 GPU 并行执行模型对 Shader 代码的约束（分支、内存访问）
- [ ] 能让 GPU 在窗口中绘制一个彩色三角形（使用 OpenGL 作为学习后端）
- [ ] 能说清楚"顶点数据上 GPU → 顶点格式解释 → Shader 逐像素计算 → 绘制命令触发流水线"这条链路与软渲染器的对应关系
- [ ] 能解释显示同步（VSync / 双缓冲）为什么能避免画面撕裂

## 阶段九：AI 驱动的现代渲染技术

**里程碑**：理解 AI 如何替换/增强传统渲染管线的各个层级，能够在自研引擎中为神经渲染预留接入点，并判断哪些方向值得立即投入、哪些只需保持跟踪。

> 与 SelfGameEngine 的关系：本阶段是阶段5渲染管线、阶段8 AI桥接、阶段9跨域Demo的**交汇深化**。你不再只是"用 GPU 画画"，而是思考"哪些画面问题可以用神经网络更高效地解决"。
>
> **核心原则**：阶段九是**按需深入**的扩展阶段，不阻塞传统图形学主线。只有完成阶段七（渲染抽象）和阶段八（现代渲染技术）后，才需要系统切入。

**验收标准（可验证）**：
- [ ] 能解释 3DGS 与三角网格表示的 trade-off（速度、质量、编辑性）
- [ ] 能说清 NTC 在材质管线中的位置：替代 BC7/ASTC，还是与它们共存？
- [ ] 能画出「低采样路径追踪 → 神经网络降噪 → 上采样」的完整链路
- [ ] 能在引擎 RenderGraph 中为神经渲染预留一个 Pass 节点

### 9.1 神经场景表示：从 NeRF 到 3D Gaussian Splatting

- [x] [[Notes/计算机图形学/AI驱动的现代渲染技术/3D Gaussian Splatting|3D Gaussian Splatting]] — 为什么需要神经场景表示、NeRF 的慢、3DGS 的可微光栅化、与三角网格的共存关系

> **与已有知识的衔接**：你在[[Notes/计算机图形学/顶点数据与索引/从OBJ文件到GPU网格|从OBJ文件到GPU网格]]里学过三角网格如何用 VBO/EBO 上传到 GPU。3DGS 提出的是另一种场景表示：不是存三角形，而是存数百万个可学习的高斯球。
> **与 SelfGameEngine 的关系**：引擎的 RHI/RenderGraph 需要扩展一种新 Primitive：Gaussian Splatting Pass。资源管线需要能加载 `.ply` 高斯球数据。
> **下一步**：纹理和材质也被 AI 改写了。

### 9.2 神经纹理压缩与神经材质

- [x] [[Notes/计算机图形学/AI驱动的现代渲染技术/神经纹理压缩 NTC|神经纹理压缩 NTC]] — 特征张量 + 轻量 MLP 解码、随机访问、运行时开销

> **与已有知识的衔接**：你在[[Notes/计算机图形学/纹理系统/纹理对象与加载|纹理对象与加载]]里学过 PNG → GPU 纹理对象。NTC 把贴图压缩成特征张量，Shader 里用一个小 MLP 实时解码。
> **与 SelfGameEngine 的关系**：材质系统需要新增"神经纹理"资源类型；Shader 变体管理要支持传统采样和神经解码两种路径。
>
> **下一步**：[[Notes/计算机图形学/AI驱动的现代渲染技术/神经网络降噪|神经网络降噪]] — 纹理存储被神经压缩革新后，渲染算法本身也能用神经网络加速。

### 9.3 神经网络降噪与上采样

- [x] [[Notes/计算机图形学/AI驱动的现代渲染技术/神经网络降噪|神经网络降噪]] — 低采样路径追踪的噪声问题、U-Net/Transformer 降噪器、辅助 buffer（albedo/normal/depth）

> **与已有知识的衔接**：你在[[Notes/计算机图形学/帧缓冲与后处理/后处理栈架构|后处理栈架构]]里学过多 Pass 后处理，在[[Notes/计算机图形学/AI驱动的现代渲染技术/神经纹理压缩 NTC|神经纹理压缩 NTC]] 里又看到神经网络可以替代传统固定函数。神经网络降噪可以看作后处理栈中的一个"智能 Pass"。
> **与 SelfGameEngine 的关系**：后处理栈新增 NeuralDenoise Pass，输入 noisy radiance + G-Buffer 特征，输出干净图像。
>
> **下一步**：[[Notes/计算机图形学/AI驱动的现代渲染技术/AI辅助3D资产生成|AI辅助3D资产生成]] — 不仅是画面，资产本身也可以让 AI 生成。

## 如何避免沉迷图形学？

> 这是本路线最重要的设计约束。

### 红线规则

| 规则 | 说明 |
|------|------|
| **阶段二后不闭关** | 完成一条绘制命令触发整条流水线后，必须开始回探引擎阶段1.2，把清屏升级为画三角形。不准"我再学学纹理再切入" |
| **阶段四后必须切** | 完成Blinn-Phong后，必须开始参与引擎阶段5.1和5.3的开发。此时你对Shader和Uniform有基础理解 |
| **阶段五后必须切** | 完成纹理系统后，必须正式参与引擎阶段5.2和5.4的开发。此时你对资源管理和渲染生命周期都有基础理解 |
| **阶段六-七不分开** | 帧缓冲/后处理/引擎渲染架构这三个阶段**必须在引擎代码里学**。不要在独立Demo里写三遍 |
| **阶段八按需深入** | PBR/阴影/Deferred可以按需深入。如果引擎暂时不需要，先了解概念，等需要时再实现 |
| **阶段九不抢跑** | AI 渲染（3DGS/NTC/神经降噪）必须在阶段七（渲染抽象）和阶段八（现代渲染）之后系统切入。不要在三角网格都跑不通时追 3DGS |

### "沉迷"的预警信号

如果你发现自己：
- 在独立Demo里实现了5种不同的高斯模糊优化，但引擎里还没有后处理管线 → **停止！回引擎！**
- 为了"完整理解"Vulkan，花两周写了一个能清屏的Vulkan程序，但引擎的RHI还是空的 → **停止！用OpenGL先跑通引擎！**
- 读了10篇PBR论文，但引擎里连一个带纹理的立方体都跑不起来 → **停止！先让立方体跑起来！**

### 正确的并行节奏

```
周1-2：    阶段二（GPU编程基础：第一个三角形）
周3：      回探引擎阶段1.2 → 把最简图形后端从清屏升级到画三角形
周4-5：    阶段三（顶点数据与索引）+ 引擎阶段5.2网格导入
周6：      阶段四（Shader与光照）+ 引擎阶段5.1/5.3 RHI/材质
周7-10：   阶段五~六 + 引擎阶段5.4/5.6 渲染生命周期/后处理
周11+：    阶段七~八 + 引擎阶段5全模块深化
周16+：    阶段九 + 引擎阶段8 AI桥接 / 阶段9 跨域Demo（按需）
```
