# GPU 编程基础索引

> [[Notes/计算机图形学/Roadmap|← 返回 Graphics Journey 路线图]]

本模块回答的核心问题：**我能在 CPU 上用 `for(y) for(x)` 逐像素画三角形了，怎么让 GPU 做同样的事？**

---

## 学习顺序

1. [[Notes/计算机图形学/GPU编程基础/软渲染器到GPU管线的映射|软渲染器到 GPU 管线的映射]]
   - 把软渲染器的每个 `for` 循环、每条 CPU 语句映射到 GPU 管线的哪个阶段

2. [[Notes/计算机图形学/GPU编程基础/CPU怎么向GPU发命令|CPU 怎么向 GPU 发命令]]
   - CPU 向 GPU 发什么（命令 / 数据 / 程序）、什么是 draw call、渲染上下文、命令通道、交换链、CPU-GPU 同步

3. [[Notes/计算机图形学/GPU编程基础/GPU的并行执行模型|GPU 的并行执行模型]]
   - SIMD/SIMT、Warp/Wavefront、延迟隐藏、分支发散

4. [[Notes/计算机图形学/GPU编程基础/把几何数据放到GPU能访问的地方|把几何数据放到 GPU 能访问的地方]]
   - 顶点数据为什么需要常驻 GPU 显存；场景顶点数据的真实量级与显存管理

5. [[Notes/计算机图形学/GPU编程基础/告诉GPU顶点数据长什么样|告诉 GPU 顶点数据长什么样]]
   - 顶点属性布局、stride/offset、交织布局、EBO 顶点复用

6. [[Notes/计算机图形学/GPU编程基础/用Shader表达逐像素计算|用 Shader 表达逐像素计算]]
   - 顶点着色器与片段着色器的分工、数据流

7. [[Notes/计算机图形学/GPU编程基础/一条绘制命令触发整条流水线|一条绘制命令触发整条流水线]]
   - 绘制命令的信息结构（状态与命令分离）、完整硬件流水线（含裁剪与透视除法）、命令的异步执行与 draw call 成本

8. [[Notes/计算机图形学/GPU编程基础/把画好的像素显示到屏幕上|把画好的像素显示到屏幕上]]
   - VSync、双缓冲、交换链、帧时间测量

9. [[Notes/计算机图形学/GPU编程基础/从OBJ文件到第一个模型|从 OBJ 文件到第一个模型]]
   - 阶段二综合实践：OBJ 解析 → VBO/EBO/VAO → Shader → 屏幕模型
