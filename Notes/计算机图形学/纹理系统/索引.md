# 纹理系统索引

> [[Notes/计算机图形学/Roadmap|← 返回 Graphics Journey 路线图]]

本模块回答的核心问题：**每个像素的基础颜色（以及更多表面属性）怎么由预先准备好的"查询表"提供？**

---

## 学习顺序

1. [[Notes/计算机图形学/纹理系统/纹理映射与UV坐标|纹理映射与UV坐标]]
   - 纹理的本质是 2D 查询表、UV 是逐顶点查询坐标、UV 展开原理、Mipmap 概念

2. [[Notes/计算机图形学/纹理系统/纹理对象与加载|纹理对象与加载]]
   - PNG 文件怎么变成 GPU 里的查询表：解码=形态翻译、上传与格式声明、三大"解释不一致"陷阱、插槽与查表器

3. [[Notes/计算机图形学/纹理系统/Mipmap与纹理过滤|Mipmap与纹理过滤]]
   - 预滤波是一次性事件、像素脚印与屏幕空间导数、查表方式三开关、各向异性过滤

4. [[Notes/计算机图形学/纹理系统/纹理寻址与采样|纹理寻址与采样]]
   - UV 超出 [0,1] 怎么办：四种 Wrap 模式的本质是四种"表的外面是什么"的假设

5. [[Notes/计算机图形学/纹理系统/多重纹理与材质|多重纹理与材质]]
   - 多表同时绑定与插槽约束、法线贴图与切线空间、TBN 矩阵、材质 = 表组 + 常量组 + 着色程序的三元模型

6. [[Notes/计算机图形学/纹理系统/GPU纹理压缩格式|GPU 纹理压缩格式]]
   - BC7/ASTC 块压缩原理、KTX2 与跨平台资源管线

7. [[Notes/计算机图形学/纹理系统/Cubemap与纹理数组|Cubemap与纹理数组]]
   - "按方向查"的六面贴图与天空盒、纹理数组 vs 图集的组织权衡、成组纹理的层级选择
