# 离屏渲染索引

> [[Notes/计算机图形学/Roadmap|← 返回 Graphics Journey 路线图]]

本模块回答的核心问题：**幕二的所有技术（后处理、阴影、延迟渲染、屏幕空间效果）都是同一句话的变种——"像素要读已经算好的像素"。而这句能力的总开关，是先把画面画到一张能读的"画布"上。** 本模块拆开这个总开关。

阶段六结束前，先记住一个觉悟：**默认画面是"递出去就收不回"的终点；一切多 Pass 都建立在"先画到中间画布、再拿它当输入"这个结构上。** 后处理、阴影、延迟渲染，全是它的用法。

---

## 学习顺序

1. [[Notes/计算机图形学/离屏渲染/离屏渲染与FBO|离屏渲染与 FBO]] ✅
   - 默认画面为什么只写不读、将场景先画到一张可读画布、颜色层与深度层各自存什么、深度层为什么默认用专用空间、画布切换的代价、组装后的完整性检查
   - **问题驱动**：模糊效果想让每个像素读到"邻居像素已经算好的颜色"，但当前管线是单向的——怎么让画面变成可读的数据？
   - **本模块增量**：你能解释"后处理为什么不能在一个 Pass 里完成"，并理解"渲染到纹理"就是把中间像素结果存成可读数据——多 Pass 世界的大门从这里打开。
