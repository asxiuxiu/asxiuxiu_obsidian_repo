# 相机状态机：常态状态的划分与组织

## 为什么状态机是地基

讨论中我顶回过一次"步子迈太大"的安排：先别聊 shake（镜头抖动）和打击感，**做相机首先要有相机**——先把常态状态想清楚、把相机状态机搭起来，因为 shake 这类效果不是独立状态，而是叠加在基础相机上的一层附加偏移。

这个直觉就是业界真实架构，叫**分层合成**：

```
最终相机 = 基础状态相机（状态机的输出）
         + 叠加层（shake、受击 impulse、FOV kick……）
```

没有底子，情绪层就是空中楼阁。这篇笔记讲的就是底子怎么打。

## 状态划分：跟着玩家需求走，别跟着动画走

新手最容易踩的坑：**相机状态的粒度按动画状态分。** 动画状态可能有上百个，相机状态通常只有个位数——因为相机只关心"这一刻玩家需要看什么"，而这个答案的变化频率很低。

一个典型动作游戏的常态清单：

| 相机状态 | 玩家这一刻需要什么 | 典型配置方向 |
|---|---|---|
| 探索（idle/走/慢跑） | 看环境、找路、看风景 | 远、高、松 |
| 疾跑 | 速度感 + 看前方远处 | 拉远、FOV 撑开（见 [[Notes/战斗3C/相机速度感的本质：屏幕上的相对运动]]） |
| 战斗常态（武器已拔出/仇恨中） | 看清敌人动作 | 拉近、压低、lag 收紧 |
| 瞄准（射击/指向性技能） | 精确指向 | 过肩、贴脸、FOV 收窄 |
| 滞空（跳跃/下落） | 看落点 | 镜头下沉倾向、pitch（俯仰角）限制放开 |
| 载具/骑乘 | 随载具特性定 | 见 [[Notes/战斗3C/相机滞后：表现力与操控感的拔河#看船与开船]] |

注意"战斗常态"和"疾跑"可能用同一套移动动画，但玩家需求天差地别——**触发相机状态切换的是玩法事件（进战斗/脱战/瞄准），不是动画标签。**

每个状态的配置项（跟拍摄影师的工作手册）：

- 站多远：`TargetArmLength`（弹簧臂长度）
- 看谁：`SocketOffset` / target offset（构图偏移）
- 视野：`FOV`
- 跟多紧：位置 lag / 旋转 lag 分开调（原因见 [[Notes/战斗3C/相机滞后：表现力与操控感的拔河]]）
- 俯仰自由度：pitch clamp（俯仰角限制，防止镜头钻地、翻过头顶）
- 怎么换：Blend 时长 + 曲线

## 组织结构：从互斥状态机到模式栈

我之前的实现是互斥状态机：探索 → 瞄准 → 探索，切完就完。业界更强的做法是**栈式组织**，可以直接读源码的参考是 UE 官方 **Lyra 示例项目**（堡垒之夜的生产级架构剥离版，不是玩具）。

Lyra 的相机叫 **CameraMode Stack（相机模式栈）**，和状态机同构但有一个关键升级：**状态不是互斥切换，而是栈式压入。**

- 底层压着"第三人称基础模式"
- 瞄准时把"瞄准模式"**压栈**——它只覆盖自己关心的参数（FOV、offset、距离），其余参数（lag 之类）继承底层
- 松开瞄准键**弹栈**，自动回到底层

好处是**可组合**：瞄准 + 疾跑 + 室内，三个模式叠着，各管各的参数，不用给每种组合写一套配置。

## Blend 的两个细节

Blend（混合）：状态切换时镜头从旧配置平滑滑到新配置，而不是瞬移。

1. **曲线要缓入缓出（ease in-out）**，匀速 lerp 会显得机械。《最后生还者 2》举枪瞬间镜头"滑"到肩后、松开又"滑"回去，那种手感就是曲线调出来的。
2. **Blend 中断处理**：正在从探索 blend 到瞄准，半路玩家松了瞄准键怎么办？朴素实现是从头再 blend 一次，镜头会"顿一下再走"；好的实现是从**当前混合中的位置**直接反向 blend 回去，速度连续。Lyra 的栈式结构天然处理这个，这也是它强的原因之一。

## 业界调参风格参考

- **《战神 2018》**：全程贴肩近景、一镜到底。战斗时镜头比探索时**更低更近**——近距离下敌人动作在屏幕上的位移幅度大、张力强，贴身肉搏的压迫感就是"喘不过气"的近。用距离换情绪。
- **《艾尔登法环》**：相机极朴素，但疾跑稳定地拉远 + FOV 微扩，是速度感三件套的通识用法。
- **《最后生还者 2》**：瞄准状态的教科书——举枪瞬间从"观察世界"一秒切换成"精确指向"，全靠过肩 offset + FOV 收窄 + blend 曲线。
