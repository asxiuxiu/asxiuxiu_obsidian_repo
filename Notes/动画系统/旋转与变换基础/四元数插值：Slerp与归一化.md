# 四元数插值：Slerp与归一化

> [!todo] 本篇核心问题
> 旋转为什么不能直接 Lerp？Slerp 在大圆上插值解决了什么？

## 为什么需要解决这个问题

上一篇 [[Notes/动画系统/旋转与变换基础/四元数的几何意义与运算|《四元数的几何意义与运算》]] 把"怎么算旋转"讲透了——旋转、复合、撤销三招。但动画里真正的常态不是"算一次旋转"，而是**在两个姿态之间连续地过渡**：角色从走路切到跑步，一两百毫秒内每条骨骼都要从"走路姿势的转角"平滑滑到"跑步姿势的转角"；转头、起跳、打招呼，全是同一件事。如果中间帧直接跳变，角色就是**"啪"地弹过去**，像定格动画漏了帧。

要平滑，就得在 A、B 两个姿态之间**插值**——按进度 t 把"中间值"算出来。

麻烦在于：位置、缩放这部分，插值是顺理成章的——`p` 从原点挪到门口，每一帧都是途中一个点，直接**按比例平均**即可，这就是 **Lerp**（Linear Interpolation，线性插值）。但对旋转，直接按比例平均四个数字是**错的**，而且错得肉眼可见：

- 中途角色会**莫名其妙地"发胖"或"缩水"**（旋转里混进了缩放）；
- 转动**忽快忽慢**，中间突然冲一下；
- 明明想转 30°，角色却**绕了个 330° 的大圈**。

这三种事故，恰好对应本篇要拆的三个原因：**离开了单位球面**、**走了弦而不是弧**、**撞上了双重覆盖**。

> 上一篇的彩蛋里已经埋了一句话：插值前要检查点积、异号就把其中一个翻转，否则会绕远路——**"这是 Slerp 与归一化篇的先决条件"**。这篇就是把那个承诺兑现到底，顺带把"为什么不能直接平均"讲透。

## 直观理解：旋转是"球面上的点"，不是"纸上的点"

用一个贯穿全篇的比喻。

**位置是纸上的点。** 一张无限大的纸代表空间，纸上每个点都是合法位置。从 A 点到 B 点插值，就是在纸上画一条直线，直线上每个点都依然"在纸上"——永远合法。Lerp 干净利落。

**旋转是球面上的点。** 上一篇反复强调过：单位四元数是"半角处方单"，它的硬规矩是**模长必须等于 1**。模长恒为 1 意味着：所有合法旋转在四维空间里恰好构成一个**单位球面**（就像所有长度为 1 的三维向量构成一个球壳）。一张处方单要合法，就必须一直躺在这个球面上。

于是插值旋转变成了一个反直觉的问题：**你必须在球面上从一个点走到另一个点，而且每走一步都还待在球面上**——离开球面，就是开出了一张非法处方单（旋转混进缩放）。

那么球面上"两点之间怎么走最自然"？答案是沿**大圆弧**（Great Circle，过这两点、以球心为圆心的那个圆）走——它相当于球面上的"直线"，是球面上的最短路径。沿着大圆弧**匀速**走完整段弧，就是本篇主角 **Slerp**（Spherical Linear Interpolation，球面线性插值）：Spherical 是"球面的"，Linear 是"线性的"——合起来就是"在球面上做线性推进"。

```mermaid
graph LR
    A[姿势 A 的旋转处方 Q₁] --> C{Slerp 插值}
    B[姿势 B 的旋转处方 Q₂] --> C
    C --> D[过渡旋转 Q(t)]
```

数据流位置：动画链路「采样 → 混合 → 蒙皮」的**混合站**——输入端是两个源姿势的旋转分量（同一根骨骼的两张处方单），输出端是一条过渡处方单。本篇讲的就是混合站里"旋转分量"这一个零件；位置和缩放零件在同一步里用最普通的 Lerp 就完成了。

## 核心机制

### 位置为什么可以无脑 Lerp

先看清楚"为什么位置没事"，才好对比出旋转的问题在哪。

位置是普通的三维坐标。`p(t) = (1-t)·p_A + t·p_B` 就是两点连线上的点——**每个中间点都是合法位置**，而且随 t 匀速推进，视觉上"匀速直线移动"，没有任何怪相。

关键在：**平面里的直线，中间点还在平面里**。位置的数据结构本身不携带"必须满足某个约束"这种包袱，所以敢直接平均。

### 旋转直接按数平均，错在哪

现在对旋转做同样的事：`q(t) = (1-t)·q₁ + t·q₂`（对四个分量分别平均）。问题立刻出现。

**第一错：离开了单位球面。**

`(1-t)·q₁ + t·q₂` 是球面上两点的连线——注意，这条"线"是**穿过球内部的直线**，线上绝大多数点**不在球面上**，模长 ≠ 1。

模长 ≠ 1 意味着什么？上一篇的 [[Notes/动画系统/旋转与变换基础/四元数的几何意义与运算#边界与坑|边界与坑]] 讲过：模长 ≠ 1 的四元数是"旋转 + 缩放"的混合体。所以中间帧的"旋转"其实暗藏着一份越变越大的缩放——视觉表现就是**角色中途发胖再缩回去**，像动画里的"橡皮人"。

**补救一：归一化，得到 Nlerp。**

把平均结果拉回球面：`q(t) = normalize((1-t)·q₁ + t·q₂)`，这就是 **Nlerp**（Normalized Lerp，归一化线性插值）。模长问题解决了，但只解决了一半：

- 归一化把"弦上的点"投影回球面——由于弦和端点共面，投影点**确实落在大圆弧上，路径没错**；
- 但**速度不均匀**：t 匀速走的是"直线弦"上的比例，投影到弯曲的球面上后，中间段角速度偏快、两端偏慢（转个 120° 的大角，中段角速度能冲到两端的 4 倍，肉眼可见地"冲"一下）。旋转尺度一大（比如转 120°），肉眼能看出"中途突然冲一下"。

**第二错：撞上双重覆盖，绕远路。**

上一篇的彩蛋 [[Notes/动画系统/旋转与变换基础/四元数的几何意义与运算#贯穿三招的彩蛋：q 和 -q 是同一个旋转|q 和 -q 是同一个旋转]] 说：处方单 `q` 和 `-q` 描述**同一个旋转**。体现在球面上就是：每个旋转在球面上有**一对对称点**（北极一个、南极也搁着一份）。

如果插值两端恰好选了"隔着球心"的那一对点（点积 < 0），无论用裸 Lerp 还是 Nlerp，都会沿**大半圈**走：该转 30° 的过渡，角色转了 330°。修复就是上一篇承诺的那句话：**先算点积，点积 < 0 就把其中一张处方单取负**（`q → -q`，反正旋转一模一样），让两端"靠到同一半球"，插值才走最短弧。**这是 Lerp / Nlerp / Slerp 任何插值的前置卫生动作。**

### Slerp：沿大圆弧，匀速

既然裸平均会离开球面、Nlerp 会变速，那"既待在球面上、又匀速"的方案就是 Slerp。

先量出两张处方单在球面上的**角距离** θ：用点积求——`θ = acos(q₁·q₂)`。点积在这里的几何意义就是"两张处方单隔着多少弧度"（这也是上一篇检查 `dot < 0` 判绕远路的同一个度量）。Slerp 的答案是：

$$
q(t) = \frac{\sin((1-t)\theta)}{\sin\theta}\,q_1 + \frac{\sin(t\theta)}{\sin\theta}\,q_2
$$

看这个式子要抓住两件事：

1. **权重从"直线比例"换成"正弦比例"**。Lerp 的权重是 `(1-t)` 和 `t`——那是给"平面上的直线"用的；球面是弯的，等比例切弦不等于等比例切弧，于是换成 `sin((1-t)θ)/sinθ` 和 `sin(tθ)/sinθ`。当 θ 很小（≈ 0）时正弦近似等于角本身，这两项权重自动退化成 `(1-t)` 和 `t`——**Slerp 在小角度下就是 Lerp**，两个公式本质是一家人。
2. **t 走的是"角度"，不是"数字"**。t 从 0 推进到 1，`tθ` 从 0 推进到 θ——角度均匀变化，**角速度恒定**。这就是"球面上的匀速直线"：旋转稳定、不冲不顿。

代码骨架（表达结构，不求可运行）：

```cpp
// flags: -O0 -g
#include <cmath>

struct Quat { float w, x, y, z; };

// 沿大圆弧匀速插值：自动处理双重覆盖（就近）与零角度退化
Quat Slerp(const Quat& a, const Quat& b, float t) {
    float dot = a.w*b.w + a.x*b.x + a.y*b.y + a.z*b.z;

    // 双重覆盖：隔了大半圈，把 b 翻成 -b 走最短弧
    float sb = 1.f;
    if (dot < 0.f) { dot = -dot; sb = -1.f; }

    // 退化：夹角 ≈ 0 时 sinθ ≈ 0 会除零，退化为线性插值（返回前归一化，略）
    if (dot > 0.9995f) {
        return { a.w + t*(sb*b.w - a.w), a.x + t*(sb*b.x - a.x),
                 a.y + t*(sb*b.y - a.y), a.z + t*(sb*b.z - a.z) };
    }

    float theta = std::acos(dot);         // 两张处方单的角距离
    float s     = 1.f / std::sin(theta);  // 把正弦权重组合拉回单位长度
    float wA    = std::sin((1.f - t) * theta) * s;
    float wB    = std::sin(t * theta) * s;
    return { wA*a.w + sb*wB*b.w, wA*a.x + sb*wB*b.x,
             wA*a.y + sb*wB*b.y, wA*a.z + sb*wB*b.z };
}
```

读代码抓三个点：① 开头 `dot < 0` 的翻转就是上一篇彩蛋的落地——点积决定走不走最近路径；② 中间 `dot > 0.9995` 是零角度退化兜底，避免 `sinθ` 除零；③ 尾部 `sin/sin` 的正弦权重，就是"沿弧匀速"的数学化身。

### 归一化：旋转运算的日常卫生

本篇标题把"归一化"和 Slerp 并列，因为它俩是同一件事的两面：

- **Slerp / Nlerp 的全部前提**（模长 = 1、点积的几何意义、权重比例）都建立在"处方单必须待在单位球面上"；
- 但浮点运算会**悄悄把模长拉离 1**——连续复合几十次、插值几轮之后，误差累积成可见的"发胖 / 漂移"。

所以归一化（`q / |q|`，把模长拉回 1）是旋转运算的日常卫生：**每从外部读入一张处方单、每做完一轮批量运算，都顺手消毒一次**。它就是上一篇 [[Notes/动画系统/旋转与变换基础/四元数的几何意义与运算#边界与坑|边界与坑]] 里"数值漂移要归一化"那一条的正式化。

### 边界与退化

- **θ ≈ 0**（点积 ≈ 1）：Slerp 公式除零，退化为 Lerp/Nlerp——反正两条路径几乎没有差别。
- **θ ≈ 180°**（点积 ≈ -1）：两端点在球面上正好相对，最短弧有**无数条**（像赤道上一对相对的点，往哪个方向绕都一样长）。此时人为选一条垂直于两者的轴即可，实战中极少出现。
- **t 超出 [0,1]**：公式依然可算，但相当于"超转"——超出端点继续往外转，动画里一般要 clamp 回 [0,1]。
- **大角度 vs 小角度**：Nlerp 便宜（只有乘加和一次归一化），Slerp 贵（要 `acos` + 两次 `sin`）。骨骼间的小转角、姿态微调这类小角度过渡，肉眼分不出两者差别，工程上常用 Nlerp 省开销；**只有大角度、长时间过渡才必须 Slerp 的匀速**。

## 混合站里的分工

上面的故事讲完了，用一张表收拢"姿势混合时每个分量该用哪把刀"：

| 姿势分量 | 插值方式 | 为什么 |
| :--- | :--- | :--- |
| 位置 | Lerp | 平面量，中间点天然合法 |
| 缩放 | Lerp | 同上 |
| 旋转 | Slerp（小角度可用 Nlerp） | 球面量：直接平均会离开球面发胖、走弦变速、撞双重覆盖绕远路 |

这个分工就是后面 [[Notes/动画系统/动画播放与混合/姿势混合：加权与跨渐变|姿势混合：加权与跨渐变]] 篇里每一根骨骼都要遵守的规则——本篇任务完成，混合站里"旋转分量"这个零件的原理已经落地。

## 一句话总结

旋转是必须待在单位球面上的量：直接对四元数做 Lerp 会离开球面（混入缩放而"发胖"）、归一化补救后的 Nlerp 会沿弦变速、双重覆盖还会绕远路；Slerp 沿大圆弧匀速插值解决这一切，而"点积选最短路径"和"归一化消毒"是插值前后雷打不动的日常卫生。
