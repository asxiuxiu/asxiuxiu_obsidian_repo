# 游戏动画系统 · 学习路线

> [!info]
> 本路线面向**有 C++、线性代数与图形学基础，且正在用 UE 源码验证概念的开发者**。动画系统是「数学 → 数据模型 → 运行时管线 → 编辑器工具」的链路：很多概念单看引擎笔记容易零散，本索引按**原理驱动**把它们串成一条主线，每阶段末尾都映射到 vault 内已有的 UE 源码解析笔记去落地。

> [!note] 前置依赖（可边学边补）
> 数学：四元数、刚体旋转、矩阵插值（→ [[Notes/数学基础/索引|数学基础索引]]）；C++：容器、模板、委托（→ [[Notes/C++编程/索引|编程知识索引]]）。

## 第一阶段：旋转与变换基础

> 动画本质是「随时间改变物体/骨骼的**变换**」。这一关把旋转的三种表示（欧拉角、旋转矩阵、四元数）和它们之间的换算讲透，所有后续阶段都建立在这上面。

|  ⬜  | 变换层级 | 局部变换 vs 世界变换、父子级联、`position × rotation × scale` 的复合 |
|  ⬜  | 插值   | 位置/缩放线性插值、旋转的 `Slerp` 与归一化、`Lerp` 混合姿势              |
|  ⬜  | 双手性  | 左手系/右手系、骨骼空间与世界空间的坐标系转换                             |
|     |      |                                                     |

## 第三阶段：蒙皮与骨骼网格

> 动画求出的是**骨骼的姿势**，但屏幕上要变的是**网格**。蒙皮（Skinning）是把顶点按权重绑到骨骼上，再随骨骼姿势变形的过程。

| 状态  | 模块   | 要掌握的内容                                                   |
| :-: | :--- | :------------------------------------------------------- |
|  ⬜  | 蒙皮矩阵 | `skin matrix = bone-ws × bone-bind^-1`、`premultiply` 的时机 |
|  ⬜  | 权重   | 每顶点最多 N 根骨骼、权重归一化、顶点双线性/高次插值                             |
|  ⬜  | 蒙皮算法 | Linear Skinning 的缺陷（糖果纸效应）、双四元数蒙皮（DQS）改进                 |
|  ⬜  | 网格数据 | 索引缓冲、材质分区与子网格、`SkeletalMesh` 与 `Skeleton` 的关系            |

## 第四阶段：动画播放与混合

> 一段动画能动了，下一步是**让角色在多个动画之间平滑过渡**。混合（Blend）解决「从一个姿势切到另一个姿势不跳变」的问题。

| 状态 | 模块 | 要掌握的内容 |
| :-: | :--- | :--- |
| ⬜ | 播放器 | 播放（Play/Stop/Pause）、播放速率、One-shot vs Loop、时间归一化 |
| ⬜ | 混合基础 | 两姿势加权平均、Alpha 过渡、`FAnimInstance` 播放与混合入口 |
| ⬜ | 骨骼混合 | 按骨骼权重混合（如上半身攻击 + 下半身行走） |
| ⬜ | 混合类型 | Crossfade、AIM Offset、Blend by Bone、逐骨骼 Mask |

## 第五阶段：动画状态机与动画图

> 动画系统真正的骨架是**状态机 + 图**。状态机管理「当前在放哪段动画、什么时候切」，动画图描述「最终姿势怎么由多路输入复合出来」。

| 状态 | 模块 | 要掌握的内容 |
| :-: | :--- | :--- |
| ⬜ | 动画状态机 | 状态（AnimState）、转移（Transition）、转移条件、打断与自动转移 |
| ⬜ | 动画图 | 节点图（根运动、混合、搜索、调整）、求值的拓扑序、`Pose` 的传递 |
| ⬜ | 状态机驱动 | 数据驱动状态（蓝图/配置文件）、状态与动画资产的绑定 |
| ⬜ | 分层状态机 | 上层状态机 + 下层混合（Full Body / Upper Body）的关系 |

## 第七阶段：物理与高级动画

> 当「手写/录制动画」无法覆盖所有情况时，用物理和算法补齐：角色碰到地面该怎么收腿？死亡时怎么自然倒地？步伐怎么贴合各向异性？

| 状态 | 模块 | 要掌握的内容 |
| :-: | :--- | :--- |
| ⬜ | 逆向运动学（IK） | 二骨骼链 IK、FABRIK、脚部 IK、视点跟随 IK、IK 求解迭代 |
| ⬜ | Motion Matching | 特征向量、动画数据库、在线搜索最佳匹配片段 |
| ⬜ | Root Motion | 由动画驱动角色移动 vs 由速度驱动动画、根骨骼的位移提取 |
| ⬜ | 物理动画 | Ragdoll（布娃娃）、物理约束、布料与头发（Verlet/轴向约束） |
| ⬜ | 动画 + 物理融合 | 动画姿势与物理模拟的插值、可控的倒地过渡 |
