# 游戏动画系统 · 学习路线

> [!info]
> 本路线面向**要在项目里调角色动画的开发者**。动画系统的核心——关键帧采样、姿势混合、状态机、混合空间、IK、Root Motion——**与引擎无关**：换成 Unity、自研引擎或纯手写运行时，概念一字不差。vault 内的 UE 源码解析笔记只作**参考实现**，用来对照这套抽象在工业级引擎里的落地形态，不构成学习主线。

> [!note] 前置依赖（可边学边补）
> 数学：四元数、刚体旋转、矩阵插值（→ [[Notes/数学基础/索引|数学基础索引]]）；C++：容器、模板、委托（→ [[Notes/C++编程/索引|编程知识索引]]）。

> [!col] 三档优先级：详略按实用性分配
> - 🔴 **必懂**：调角色动画时天天打交道的概念。逐篇写透——机制推导、典型坑、数值边界一个不少。
> - 🟡 **常用**：项目里定期会遇到。讲清机制与典型场景，不穷尽边角。
> - ⚪ **了解**：多数项目用不到。合并成速览篇，知道「是什么、什么项目才需要它」即可，用到再按参考实现深挖。

## 学习路径总览

动画系统的主线是一条数据流：**一份姿势数据从资源文件出发，经采样、混合与状态机裁决、参数驱动、IK 修正，最终变成蒙皮矩阵送上屏幕**。

```mermaid
graph LR
    A[动画资源<br>关键帧] --> B[采样<br>按时间取姿势]
    B --> C[混合 / 状态机<br>加权出一个姿势]
    C --> D[IK 等后处理<br>修正姿势]
    D --> E[蒙皮矩阵]
    E --> F[渲染]
```

第一块（🔴）沿这条数据流逐站展开，「旋转与变换」是所有站的数学地基；第二块（🟡）是站稳之后的常用进阶；第三块（⚪）是概念速览，随时可读。
